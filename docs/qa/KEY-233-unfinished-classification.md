# KEY-233 미완성 항목 분류 기준선

기준 커밋은 `origin/develop`의 `c1fcded`이며, 정본은
`frontend/js/frames.js`의 64개 프레임이다. 현재 `level !== 1`인 미완성
프레임은 53개다.

- WP-F(KEY-235) 안내 화면 인계: 17개
- 후속 구현: 36개
- 삭제 후보: 0개

ID 목록은 검사가 읽는
[`KEY-233-unfinished-classification.json`](KEY-233-unfinished-classification.json)에
고정했다. 각 항목의 화면명·현재 단계·차단 근거는 `frames.js`의 같은 ID에 있다.
검사는 53개 항목이 정확히 한 분류에만 속하고, WP-F 목록이
`needsGuideScreen()` 결과와 일치하는지 확인한다.

## 기존 “63건”과의 차이

Jira KEY-233과 계획 문서에는 “미완성 구현 63건”이라는 숫자만 있고, 그 63건의
원본 ID·파일·행 목록은 첨부·댓글·저장소에 없다. 따라서 현재 코드에서 근거 없이
10건을 만들어 63건으로 맞추지 않았다. 원본 진단 목록을 받으면 이 기준선과 ID로
대조해 완료·삭제 후보·WP-F·후속 구현 네 범주로 이관해야 한다.

삭제 후보는 이희진 확인 전까지 실제 삭제하지 않는다. 이번 기준선에서도 기존
9/3 데모 동작 버튼을 삭제하거나 비활성화하지 않았다.
