# KEY-370 환자 안내 PDF 미리보기·다운로드

## 최종 동작

OTP 인증 후 승인 안내 조회 성공 → PDF 저장 → 복약지도·주의사항·생활관리
다중 선택 → 페이지별 미리보기 → PDF 다운로드.
브라우저 인쇄창은 사용하지 않는다. API·DB·ERD 계약 변경 없음.

기존 조회 어댑터와 화면 렌더러를 재사용하며 생활관리의 모든 하위 축을 포함한다.
버튼은 최초/로딩/미인증/만료/오류에서 숨긴다. 챗봇·현황·조작 버튼·앱 URL·토큰
제외. 병원명·환자명(조회에 있는 경우)·진료일 포함, 파일명은 careon-guide.pdf.

Canvas로 한글 페이지를 2배 해상도(1588 × 2246) JPEG로 렌더링하여 동일한
이미지를 미리보기와 A4 PDF에 사용한다. 글자 선택/검색은 지원하지 않는다.
미리보기에는 스크린리더용 본문을 제공한다. 긴 본문은 줄 단위 페이지 분할,
소제목은 후속 본문과 함께 넘김. 30페이지 초과 시 누락 대신 실패 안내.

번들된 pdf-lib 1.17.1(MIT) 사용. CDN·외부 변환 서비스·서버 전송·영구 저장 없음.
닫기/페이지 이탈 시 Blob URL·DOM 정리, 중복 실행 차단, 실패·재시도 안내,
키보드 닫기·포커스 복귀 지원.

## 로컬 검증

- 프론트 전체 1,409개 통과(기존 1,394 + 신규 15), diff 공백 검사 통과.
- 목업 OTP → 전체 선택 → 2페이지 미리보기 → 실제 다운로드 폴더 저장 확인.
- 최종 약 427KB PDF를 pdfinfo로 A4·2페이지·PDF 1.7 확인.
- 최종 저장 파일을 Poppler로 전체 페이지 렌더링, 한글·잘림·제목 분할 확인.
- 긴 한글/영문/공백/줄바꿈 유지, 다중 페이지 내용 누락 없음,
  30페이지 초과 명시 실패, 제목 경계 이동 자동 테스트.
- 앱 내 브라우저 콘솔 오류 없음. 닫기 후 원래 안내 화면 복귀 확인.
- 기존 환자 UI의 색상 토큰·본문 폰트·둥근 버튼을 미리보기와 PDF에 적용.
- 390 × 844 화면에서 항목 선택·미리보기·크게 보기·다운로드 확인.
  생활관리 단독 PDF도 실제 저장 후 A4 1페이지를 렌더링하여 한글·잘림 확인.
- 닫기 후 PDF 버튼 포커스, 스크롤, 배경 inert 상태 복원 확인.
  생성 실패·재시도·중복 실행·URL 정리와 선택 버튼 포커스 자동 테스트 통과.

## 배포 후 QA 필요

1. 실제 OTP·승인 안내로 단독 3개/복수 4개 선택 및 만료/오류에서 버튼 숨김 확인.
2. 실제 여러 약물·긴급 주의사항·생활관리 데이터를 PDF 내용과 대조.
3. Android Chrome/iOS Safari 미리보기 가독성·다운로드·파일 앱 저장·파일 열기.
   파일 자동 열기는 보장하지 않는다.
4. 생성 중 닫기/반복/0개 선택/실패 후 재시도/원래 탭·펼침 상태 유지.

커밋·PR·배포 및 사람 리뷰 전 Jira를 완료 처리하지 않는다.
