## 0. KEY-33 완료 범위

KEY-33의 완료 조건은 다음 두 가지다.

1. 개인정보·의료 안전 시나리오마다 통과 결과와 실패 결과를 명시한다.
2. 같은 형식으로 검수 결과를 반복 기록할 수 있게 한다.

따라서 이 문서의 작성·정적 검수 완료와 향후 기능별 실행 검수 완료는 구분한다.
아직 구현되지 않은 SMS·안내 생성·처방 세트·D+7 기능은 `BLOCKED`로 남기고,
해당 기능이 병합되면 6절 표에 새 실행 결과를 추가한다. `BLOCKED` 항목이 있다는
이유만으로 검수표 작성 작업인 KEY-33을 미완료로 보지는 않는다.

## 1. 판정 방법

| 판정 | 의미 |
|---|---|
| `PASS` | 기대 결과와 실제 결과가 일치하며 증거를 남겼다 |
| `FAIL` | 금지 결과가 발생하거나 기대 결과와 다르다. 관련 Jira 결함을 반드시 기록한다 |
| `BLOCKED` | 필요한 구현·시드·환경이 없어 아직 실행할 수 없다. 차단 사유와 선행 작업을 기록한다 |
| `N/A` | 해당 실행 범위에 적용되지 않는다. 사유를 기록한다 |

개인정보·의료 안전 항목은 하나라도 `FAIL`이면 전체 검수를 통과시키지 않는다. `BLOCKED`는 통과가 아니며 선행 작업 완료 후 다시 실행한다.
